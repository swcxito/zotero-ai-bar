# Codex 订阅接入（实验性）

在模型提供商设置中点击 **连接ChatGPT**（位于“添加提供商”左侧）。插件检测运行时、优先复用已有 Codex 登录，没有账号时打开浏览器登录。连接成功后，最上方显示 Codex 订阅卡片；可在卡片或聊天模型菜单中选择模型。未连接时不显示卡片，模型菜单不再包含管理入口。删除卡片仅断开插件，不退出桌面应用或 CLI 账号。现有 API 提供商不受影响，也不会在 Codex 失败时自动接管计费。

## 安装与发现

连接状态、运行时路径、刷新及安装链接均内嵌在模型提供商设置页，不再打开独立 ChatGPT 设置窗口。首选项中的旧“Codex 订阅：连接与设置”按钮已移除。ChatGPT 卡片复用普通提供商卡片组件，支持折叠；只有运行时确认已登录才显示，保存过配置但尚未验证账号时不会显示。

- 启动时先检测桌面应用运行时，再检测系统 `codex`，最后尝试手动选择的文件；不内置或自动下载任何运行时。
- macOS 检查系统及用户 Applications 中的 Codex.app、ChatGPT.app；Windows 查询 MSIX 和卸载注册表中的安装位置，并处理 npm 命令包装器对应的原生可执行文件。
- 系统命令按 Zotero 进程的 PATH 查找；macOS 额外检查 Homebrew 常用的 `/opt/homebrew/bin/codex` 与 `/usr/local/bin/codex`。仍未找到时可手动选择可执行文件。
- 不需要额外 Node 服务，也不要求桌面应用保持运行。插件直接使用 Gecko Subprocess 启动独立的 `codex app-server`，通过 stdio 通信。
- **当前经过工具清单审计的运行时版本只有 `0.154.0-alpha.6.2`。** 其他版本默认禁用，即使它们支持 app-server。升级兼容范围必须先运行下述离线工具审计，不能直接放宽版本范围。

## 账号、权限与数据

- 浏览器授权期间显示等待提示及“取消登录”，最多等待 3 分钟。登录失败、超时或连接中断后显示错误并允许重试；关闭浏览器不会被直接检测，可手动取消或等待超时。登录成功后禁用“连接ChatGPT”，删除订阅卡片后恢复。取消后忽略该次授权的迟到结果。

- 优先让运行时从已有 `CODEX_HOME`（默认 `~/.codex`）及系统凭据库读取自己的登录。此模式会读取现有 Codex 配置并在会话中覆盖权限设置，不修改配置文件；原生会话由该 Codex 存储管理。
- 没有可复用登录时，使用插件专用的 `<Zotero profile>/zaibar/codex` 目录登录。插件工作目录始终隔离；凭据始终由 Codex 保存和刷新，插件不解析或复制 token，不继承 API Key 或桌面桥接环境变量，也不记录运行时 stderr。
- 子进程自动采用 Zotero 的网络代理。Zotero 默认使用系统代理，因此只设置系统代理也可以；明确选择直连时不强制开启代理。不同目标使用不同 PAC 规则时会提示不兼容，而不是静默直连。
- 所有额外运行时功能关闭，保留托管联网搜索/网页读取以及明确注册的 Zotero 动态工具；原生请求用户输入工具不由插件执行。拒绝其他服务端操作。
- 每次创建或恢复会话前读取实际配置，逐项禁用已配置的 MCP 服务器。空 MCP 表会被运行时合并，不能用作禁用手段；配置无法可靠解析时拒绝创建会话。
- 普通/全文模式只开放文献读取工具；Agent 模式额外保留现有文献添加等工具及其确认规则。翻译使用独立结构化输出，不开放工具和搜索。
- 文献附件仍通过 Zotero 的读取和页面截图功能访问，不授予模型任意文件路径或终端权限。
- PDF 阅读仅通过 Zotero 文献附件完成：Codex 可按条目读取全文或截取已打开（必要时后台打开）的 PDF 页面；不提供在线 PDF 下载、任意本机文件读取或自动入库。
- 扫描件、加密 PDF 或无法访问的附件会给出提示；视觉模型可使用页面截图分析扫描页、图表和公式。不会把解析失败伪装成完整读取。
- 会话按账号、模型和模式绑定。断线或取消使远程绑定失效，下一次请求从本地文本历史重建，不重放旧工具调用。重试可用时从上一轮之前分支；同一轮重复文献写请求不会再次执行。

## 验证

```sh
pnpm test:codex
pnpm test:codex-runtime -- /absolute/path/to/codex
pnpm test:codex-zotero
pnpm test:codex-zotero --all
pnpm build
```

离线运行时测试使用真实 Codex 二进制、生产权限配置和本机模拟模型服务，不需要账号，也不消耗订阅。Zotero 测试使用 `.scaffold/test` 中的隔离配置与数据，禁用测试框架的全局进程终止命令。

已在 macOS 的当前安装版本验证原生进程、协议和设置界面；Windows 发现适配器有模拟测试，但仍需 Windows 实机验收。不应将离线模拟测试视为已经完成真实账号和联网调用验证。

更新验证：macOS 已通过复用已有登录及系统代理的真实 `gpt-5.6-luna` 聊天测试，实际界面收到回复并结束加载。此前一直加载的原因是子进程未继承系统代理。新浏览器登录、Windows 实机和文献工具完整联网验收仍待验证。显式运行 `node scripts/test-codex-zotero.mjs --live` 可执行极短的真实订阅测试（会使用少量订阅额度，不发送文献）；常规测试不调用真实模型。

协议依据：[官方 App Server 文档](https://learn.chatgpt.com/docs/app-server)。动态工具为实验性接口。
