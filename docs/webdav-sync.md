# WebDAV云同步

在 Zotero 设置 → Zotero AI Bar → **WebDAV云同步** 中配置服务器地址、账号、应用密码与远端目录。

- **双向同步**：合并聊天历史、提示词、模型配置与插件设置。服务器需要提供强 ETag 并支持条件写入；发生并发修改时自动重新合并，连续冲突则停止并报错。
- **上传覆盖云端**：以当前设备内容覆盖云端快照，请仅在确定以本机为准时使用。
- **从云端拉取合并**：合并云端内容，不上传本地数据。
- **自动同步**：启用后在启动时及每 30 分钟运行一次。

“同步模型提供商 API 密钥”默认关闭。开启后，密钥会作为 JSON 内容上传到所选服务器；同步文件本身不额外加密。WebDAV 应用密码保存在 Zotero 的 Login Manager 中，在支持的版本上同时使用 OSKeyStore 加密，不随同步快照上传。

同一 Zotero 库使用 itemKey 关联文献；分别导入的文献依次尝试 DOI、ISBN、标题＋首位作者姓氏＋年份。存在多个匹配条目时保留未关联状态，不自动选择。该功能不会合并 Zotero 文献或附件。

建议使用 HTTPS，并在首次同步前备份插件数据。连接测试会创建、读回并删除一个临时文件。
